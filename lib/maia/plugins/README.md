# Plugins

See docs/plugins.md

The plugin structure allows MAIA functionality to be packaged into reusable plugins.

Each plugin is stored in its own directory named after the plugin:

```text
<pluginname>/
├── tools/
├── profiles/
└── skills/
```

## Tools

The `tools` directory contains tools provided by the plugin.

## Profiles

The `profiles` directory contains profiles provided by the plugin.

## Skills

The `skills` directory contains skills provided by the plugin.
